# DevelopersHub AI/ML Engineering Internship Tasks

## Task 4: General Health Query Chatbot


## Task Objective
Build a general health query chatbot that answers basic health-related questions using a Large Language Model with proper safety controls.



## Dataset Used
No traditional dataset was used.  
The chatbot uses a pre-trained Large Language Model from Hugging Face (Mistral-7B-Instruct).



## Models Applied
- mistralai/Mistral-7B-Instruct-v0.2 (Hugging Face)
- Prompt Engineering for controlled responses
- Rule-based Safety Filtering



## Key Results and Findings
- The chatbot successfully answers general health-related questions in a friendly and simple manner.
- Prompt engineering helped control tone and prevent medical diagnosis or prescriptions.
- Safety filtering reduced the risk of harmful or dangerous medical advice.
- Conversation memory improved user experience by maintaining context.
- The reset function allows starting a new conversation without rerunning the notebook.
- Large Language Models can effectively power safe and informative health assistants.
- Proper prompt design and safety handling are essential when building medical chatbots.
